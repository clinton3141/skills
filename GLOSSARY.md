# Skills

Agent Skills for a personal engineering toolkit, written to work across agent vendors.

## Reviews

**Persona review**:
A review of a change through one persona's lens (Chad, Clive, Jimmy or Poindexter), written for a human reviewing their own code or someone else's.
_Avoid_: perspective, reviewer

**Sweep**:
A persona review through all four personas at reduced depth, to show which personas are worth running in full.
_Avoid_: review-all, full review

**Spec review**:
An agent's check of its own implementation against the originating spec and the repo's coding standards.
_Avoid_: code review, self-review

**Codebase audit**:
A review of the whole repository for cohesion, chiefly of agent-architected code, that files one issue per finding.
_Avoid_: full review, intensive review
